Пересчитывает relatives, child_of, parent_in и grandparents заново — исключительно из families и nodes (источник истины). Устраняет «призрачные» серые карточки в дереве (например «P47»), которые остаются после объединения или удаления персон, если производный кэш не был синхронизирован. Данные персон и семей не меняются — затрагиваются только производные связи. Автоматически создаётся резервная копия перед изменением.
Пароль для родственников (гостевой доступ) можно сменить здесь — без переразвёртывания сервера. Новый пароль вступает в силу немедленно для всех новых входов. Пароль администратора отсюда не меняется — только гостевой.
Загрузите JSON-файл в одном из двух форматов:
1) готовый патч: { "patches": { "P42": { "birth": "1888" } } }
2) объект персон — весь nodes из дерева (или полный файл дерева с ключом nodes), или его часть: { "P42": { "birth": "1888" } }. Каждое поле каждой персоны сравнивается с текущими данными на сервере, в патч попадают только реально изменившиеся значения.
Разрешённые для правки поля: name, birth, death, birth_he, death_he, hebrew_name, sex, rel, rel_en, rel_he, name_en, name_he, phone, email, social, bio, photo, missing, gen — остальные поля в файле игнорируются (клиентом и сервером одинаково).
